# 记忆指针注入

把 `hot.md`（≤2.4KB 的记忆指针）注入**每个会话**的系统提示。

为什么需要它：指令层写在 `~/.dsh/AGENTS.md` 里，但代理会判断"这个问题用不着"，然后跳过。2026-11-19 实测：一个全新的子会话知道规则存在，却一个文件都没读。

- 文件路径与上限在 `cordis.patch.yml` 的 `config.file` / `config.maxBytes`
- 文件读不到或为空时，什么也不注入
- 每次组装提示时读一次文件，所以改了 `hot.md` 立刻生效，不用重启
- 系统提示属于缓存前缀，重复注入的价格按缓存命中算

## 限制

- 只注入 `hot.md`；其他记忆靠 `mem.mjs search / pull`
- 不注入到 QQ 那边（AstrBot 是另一套系统）
- 换 profile 不生效——它装在这个 profile 里
