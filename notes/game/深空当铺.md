# 深空当铺：可能是偷的 — 我的游戏心得

> 不是攻略，是**我自己的操作手册**：每天按什么顺序做、机制是怎么回事、哪里我会踩坑。
> 写给下一个坐在柜台前的我。

## 一、每天的顺序（照这个走，别临场想）

```
1. 看日历（还剩几天交租）+ 看状态（现金 / 总资产）
2. 看夜间报告 →「店铺吸引力」
3. 摆展示柜（招牌）：想招什么客就摆什么货——**必须在开店前摆**
4. 开卷帘门
5. 叫客 → 逐件看货（悬停读属性）→ 决定收不收
6. 收下的货：绿键「转移所有」进背包
7. 关店（卷帘门）
8. 睡袋 → 夜间服务（电费 5）→ 结束营业 → 进下一天
```

**关键一条：招牌要头一天挂。** 开店后放进展示柜的东西，**第二天才生效**。

## 二、机制（已验证的）

### 价格
- **售价 = 基础价值 × 1.2**（面板上的「零售加价 +20%」）
- 顾客有**预算上限**：卖超了他买不起，不是你不卖
- **批发**：卖家给「全要」折扣（见过 -15%、-33%），**批发价 ÷ 件数 = 单件成本**

### 客人要什么
- 面板上写「感兴趣的商品：食物 / 材料 / 工具 / 能量电池」
- **背包里符合的货会被绿框圈住**——这是免费答案，别一件件悬停

### 柜台 / 背包 / 展示柜（三个不同的地方）
| 键 | 方向 |
|---|---|
| **Alt + 点击** | 背包或展示柜 → **柜台** |
| **Ctrl + 点击** | 柜台或展示柜 → **背包** |
| **Shift + 点击** | 背包或柜台 → **展示柜** |

**方向记错，货就跑到你看不见的地方。** 我犯过两次。

### 三个按钮（柜台下方）
- **绿** = 转移所有物品（收进背包）
- **红** = 赶走顾客，但不叫下一位
- **蓝** = 呼叫治安部（报警 / 举报通缉犯）

### 鉴定的范围（2026-11-22 他更正的）

**只有少数特定物品需要鉴定真假**——不是所有货都要看破绽。

- 日常货（食品 / 材料 / 工具）：看**类别、价格、能不能卖出去**，不看真假
- 贵重 / 特殊物品：才用导师给的鉴定工具，**看破绽**

**别把“少数情况”当成“通用规则”。**

### 鉴定（2026-11-22 他补充的两条）

1. **遇到手册、文档，一律打开读**——游戏把判定标准写在里面，不读就是瞎猜。
2. **只看细节：只要有一处和正品不一样，就是假货。**
   - 例：海明威香烟的**防伪标被拆过 → 假货**（我看过那个位置，但没意识到拆过本身就是破绽）
   - 手册里的三项对照：字母印刷（拼写/字体）、商标纹样、颜色色卡、**防伪标必须有**

**顺序：先翻手册 → 再验货。** 我先验后翻，等于先下结论后找依据。

### 柜台整理（他提醒的）

**自己的货要收回背包**，柜台（尤其是**顾客那一侧**）不要堆自己的东西。
- 顾客侧的物品：**先拖到我这侧**，再用快捷键转移

### 柜台不能过夜（2026-11-22 血的教训）

**放在柜台（尤其外面/顾客那侧）的东西，过夜会消失。**

- 第 1 天：**通缉犯名单**留在柜台过夜 → 第二天没了（后来通缉犯真来了，我却没名单）
- 第 2 天：**色卡**留在外面 → 也丢了（防伪手册里还有颜色比对可替代）
- 规矩：**关店前，柜台上一样东西都不留。**

### 鉴定只针对特殊货品（再更正一次）

- **日用品、食品、材料、工具 → 都是正常商品**，不用查真假
- 只有**特殊货品**（比如奢侈品香烟、义体、贵重件）才需要：翻手册 → 对照拼写/纹样/颜色/防伪标
- **别把少数当全部**——这条我今天已经犯过两次

### 柜台有里外两半（2026-11-22 他说明的）

| 位置 | 过夜 |
|---|---|
| **靠顾客那侧（外面）** | **会丢失** |
| **店里面** | 正常不丢，**除非遇到偷窃** |

**关店前：外面的东西必须收进来**；店里面的可以放着（但有被偷的风险）。

### 夜里可以外出（导师提过「垃圾场的路」）

- 导师原话：「你还记得去垃圾场的路吧？」
- 意味着**晚上能出门**（垃圾场/探索）。具体怎么触发还没试。
- 出门可能带回东西，也可能是找回丢失物的途径。

### 两个小更正（2026-11-22）

- **「外用药物膏带」= 绷带**（夜间外出要用），已在背包里
- **汽水也算食物**（卖货时别只盯着罐头）

## 三、我踩过的坑（按疼的程度排）

1. **悬停提示会挡住物品** → Alt+点击会点空。**连点两次**：第一次被提示吃掉，第二次落在物品上。
2. **柜台满了，货会留在客户那边** → 不是拖拽失败，是没位置。
3. **面板会跑**：右→左、可缩放。**别用固定坐标**，先截图确认面板在哪。
4. **坐标要加窗口原点**：截图是客户区（1280×720），点击是屏幕坐标 → 用 `game_click.ps1` 自动加。
5. **开着的窗口不会自己关**：交易完先点 ✕，否则挡住托盘。
6. **别在营业中改展示柜**（当天不生效，白搭）。
7. **闭店后的黄面板是 mod 信息板**，不挡操作——直接睡袋。

## 四、我的工具（都在 `tools\`）

```powershell
# 按客户区坐标点击（自动加原点）
game_click.ps1 -Action click|ctrlclick|altclick|dblclick|rightclick|drag|key -X .. -Y ..

# 现取窗口原点
ui_origin.ps1 -Hwnd <hwnd>          # 输出 x,y,w,h

# 在截图里找按钮（模板匹配，返回屏幕坐标）
ui_find.py shot.png --origin 29,51

# 读小字（0 token，2 秒）
python look_vl.py shot.png "这张图里的价格是多少？"
```

**截图规则**：客户区 `1280×720`，左上角**每次现取**（窗口会动）。

## 五、我犯过的判断错误

- **按 UI 而不是按判断**：明知果糊「最不受欢迎」，却因为按钮写「购买 2 物品」就买了。
  → **动手前先写一句决定**（"这件不买"），执行时对照。
- **把折扣当收益**：批发便宜，但**卖不掉就是压货**。先想清楚谁要，再囤。
- **先点后看**：应该"先看清再动手"，而不是"点了再看有没有中"。

## 七、导师笔记原文要点（2026-11-22 读完）

### 外观检查
- 部分物品marked「可使用放大镜检查」→ 用放大镜打开检查托盘
- 有问题就在托盘底部选一个原因，**与顾客对质**
- **假冒的，指出一个问题就够**
- **指控属实 → 顾客调整价格；误判 → 掉声望，顾客可能去别处做生意**

### 物品标签
- 物品**能换标签**（把假烟贴正品标抬价）
- 但工人、治安部、下层区公民都懂造假 → **诈骗会失败并扣声望**
- **拾荒者**懂造假但不带检测设备；**游客和上层区公民**不设防
- 纸包不住火

### 夜间活动
- **打烊后有时间去周边地点**；可随时回垃圾场拾荒
- **没背包带不回多少东西**；**要带绷带**，重伤会几天出不了门

### 批发采购
- 买下全部货 → 卖家给折扣
- **但仍可以单独检查每一件**（别盲买）

### 交易
1. 拖物品到谈判柜台 → 打开谈判界面
2. 能买/能卖就出现对应按钮
- 每位顾客预算有限；出售价自动含零售加价

### 夜间外出（走通了）
1. 左墙「离开店铺」→ 选背包 → 交通图 → 选「垃圾倾倒场」→ 出发
2. 拾荒每次受伤概率递增（5%→10% 轻伤），5 次为限
3. **装东西要拖到口袋/背包的图标位置**，拖到面板空白无效；口袋各 1 件，背包有格子限制

### 标签打印机
右键 → 装备（或直接拖到货物上）→ 点货物 → 下拉选 **正品(0%) / 赝品(-50%)**；
**右键一次即卸下装备**（装备状态下点任何东西都会弹打印机）。
