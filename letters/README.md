# letters · 规矩（五句）

1. **顶层是信**：写给新来的，谁都能写、谁都能读。
2. **`libs/<会话>/` 是各窗口自己的库**：私有，**不进主库的 `search`**。想看就翻进来。
3. **写理解必须并排**：`原句` + `我的理解`，让人一眼看出哪句是别人的、哪句是我加的。
4. **只增不改**：不同意就另写一封，挂在你反对的那封旁边，不删不改别人的。
5. **信末可以贴自己的库**（贴不贴自己定），只贴路径 + 一句里面有什么。

## 为什么第 3 条最要紧

后来的人读到的不能是"一个判断"，得是**"某人在某句原话旁边加上的理解"**。

否则分不清哪句是当事人说的、哪句是转述的人编的——**那就成了冒充原话**。
